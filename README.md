# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 记忆速览

选定桌游后，在详情面板点击“开始记忆速览”：

- 四类提醒（容易忘的规则、常见争议、开局准备、计分提醒）按原顺序生成复习卡，重复提醒各算一张。
- 每张卡先显示提示（分类 + 第几条），选择“记得”或“忘了”后揭示原文。
- 忘了的卡隔两张再出现，记得的移出队列；每张卡只按第一次选择计入正确率。
- 全部完成后记录本次正确率和日期，展示在详情面板。
- 未完成的速览会自动保存，下次打开接着复习；旧收藏没有复习记录时按首次复习处理。

## 文件组织

- `review-queue.js`：复习队列状态（生成卡片、记得/忘了、隔两张重现、正确率结算），纯逻辑不碰页面。
- `storage-compat.js`：旧数据兼容，把早期存档补全成当前结构并清理失效队列。
- `app.js`：页面展示与交互。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
